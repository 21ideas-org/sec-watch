# sec-watch

Сайт [sec.21ideas.org](https://sec.21ideas.org) — критические security-оповещения
для биткоинеров. Публикации сюда кладёт бот
[`security-watch`](https://github.com/21ideas-org/security-watch) одним запросом
в Contents API; Actions собирают и деплоят на GitHub Pages.

Astro без фреймворков, статика.

```
npm install
npm run dev
```
